Find the Python dependencies with no prebuilt wheel for your platform, before your build does

Switching to an ARM image, Alpine, Windows on ARM, Python 3.15 or free-threaded 3.14t, and seeing Failed building wheel? wheelgap reads your lockfile and lists every package pip or uv would have to compile from source, or can't install at all, on the platforms you ship to. With --fix it gives the upgrade that has the wheel and the command to run.

uvx wheelgap -p 3.13 -t linux-aarch64,musl-aarch64 --fix

Free and open source (MIT). No account, nothing to install permanently.

Projects

  • wheelgap: the command-line tool, GitHub Action, agent skill and MCP server. Documentation.
  • Repo checker: paste a public GitHub repository and see its gaps in the browser.
  • Wheel coverage tracker: the top 5,000 PyPI packages by platform and Python version, updated nightly, with a page for each package.
  • Gap wheel index: unofficial wheels PyPI is missing, built twice from PyPI's sdist and published only when both builds match.
